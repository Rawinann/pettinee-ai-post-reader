# เปิดดึงและตอบอัตโนมัติ

ระบบ Cloud ใช้ worker เครื่องเดิม ไม่ต้องใช้ API ของ Facebook เพิ่ม หน้าเว็บปิดได้ แต่เครื่อง worker ต้องเปิด มีอินเทอร์เน็ต และ Facebook ยังล็อกอินอยู่

## อัปเดตครั้งแรก

1. เปิด PowerShell ในโฟลเดอร์โปรเจกต์ ตั้ง `DATABASE_URL` ของ Neon แบบเดิม แล้วรัน `npm.cmd run cloud:migrate` เพื่อเพิ่ม migration `002-automation` คำสั่งนี้ไม่ลบโพสต์เดิม
2. รอ Vercel deploy commit ใหม่เป็น Ready แล้วรีเฟรช Dashboard
3. หยุด worker เก่าแล้วเปิดใหม่ด้วย `start-pettinee-page-worker.cmd` หรือ `start-pettinee-worker.cmd` ตรวจบัญชีใน Chrome ให้ตรง
4. หน้า **ภาพรวม** เลือก worker ในกล่อง **ดึงและตอบอัตโนมัติ** ตั้งรอบดึง (เริ่มต้น 60 นาที ครั้งละ 40 โพสต์) และจำนวนส่งสูงสุด (เริ่มต้น 6 โพสต์ต่อชั่วโมง)
5. กด **เปิดดึงและตอบอัตโนมัติ** ครั้งเดียว ระบบจะดึงทันทีในรอบที่ worker รับคิว แล้วทำต่อเป็นรอบโดยไม่ต้องกดส่งทีละโพสต์

## เงื่อนไขการตอบ

- เฉพาะโพสต์กลุ่มที่ worker ที่เลือกเก็บเข้าระบบเป็นครั้งแรกหลังเปิดโหมด ไม่ไล่ตอบโพสต์เก่า และไม่นับโพสต์ซ้ำเป็นงานใหม่
- จับคู่ไกด์จาก catalog เดิม ค่าความใกล้เคียงขั้นต่ำ 0.25 เป็นคะแนนจัดอันดับ ไม่ใช่ความแม่นยำทางการแพทย์
- เก็บข้อความต้นทางตามเดิม ร่างคำตอบใหม่เป็นประโยคบอกเล่า ไม่ถามคำถามต้นทางซ้ำ ไม่แต่งประสบการณ์หรือรับรองว่าอาการปกติ
- เคสฉุกเฉิน ข้อความที่ยังถูกย่อ เรื่องยา ข้อกล่าวหาการรักษา คำสั่งฝัง หรือไม่มีไกด์ที่ตรง จะรอให้คนตรวจ
- ระบบตรวจบัญชี ข้อความโพสต์ และร่างก่อนส่ง และเก็บลิงก์คอมเมนต์เมื่อยืนยันได้ ถ้าส่งผิดพลาดหรือไม่ทราบผล จะพักอัตโนมัติให้เปิด Facebook ตรวจ ไม่ส่งซ้ำเอง
- ใช้ Ollama บนเครื่องตามค่าของ worker ถ้าเลือก OpenAI ยังต้องตรวจข้อความก่อนส่ง API ตามเงื่อนไขเดิม โหมดอัตโนมัติจะใช้แม่แบบเมื่อยังไม่ได้ตรวจข้อมูล

## หยุดและดูผล

กด **หยุดอัตโนมัติ** ยกเลิกงานอัตโนมัติที่ยังอยู่ในคิว งานที่กำลังส่งแล้วอาจหยุดไม่ทัน โพสต์ที่ส่งแล้วดูใน **ตอบแล้ว** ส่วนโพสต์ที่พักให้ดูในกล่องโพสต์และประวัติคำตอบ เปิดโหมดใหม่จะเริ่มรอบใหม่ ไม่ส่งคิวเก่าที่หยุดไว้

ลิงก์ในคอมเมนต์เป็น `https://pettinee-ai-post-reader.vercel.app/g/...` ผู้ใช้เปิดหน้า Pettinee แล้วกดอ่านคู่มือ ดูยอดที่ **การเข้าชมคู่มือ** แยกเปิดหน้าเรา / กดไปอ่านคู่มือ เป็นจำนวนครั้ง ไม่ใช่จำนวนคนไม่ซ้ำหรือการอ่านจบ บอต/preview ที่รู้จักถูกแยกออก แต่ยังกรองบอตไม่ได้ทั้งหมด

การทดสอบใน repo ใช้ PostgreSQL WASM และตัวส่งจำลอง ไม่ได้โพสต์คอมเมนต์จริง และยังต้องตรวจรอบจริงด้วยบัญชีและกลุ่มที่ใช้งาน
