# ใช้ประโยชน์จากโพสต์โดยยังไม่มีคอมเมนต์ครบ

ตรวจไฟล์ `data/Pettinee_Facebook_200_Posts_Public_Excerpts_19Nov2026.xlsx` แล้วพบ 200 ลิงก์ในชีต `โพสต์ 200 รายการ` มีข้อความตัดตอน 179 รายการ อีก 21 รายการไม่มีข้อความ ไม่ใช่ข้อมูลโพสต์เต็ม แหล่งข้อมูลเตือนว่าอาจมีคำอธิบายที่ Meta สร้างปะปน

ชีตคอมเมนต์มีข้อความตัดตอน 21 รายการจาก 20 โพสต์ ส่วนชีต Raw เพิ่มเติมเป็นช่องว่าง 2,000 ช่อง ไม่ใช่คอมเมนต์จริง โหมดหลักรอบนี้ใช้เฉพาะชีตโพสต์ ไม่รวมคอมเมนต์สองชีตนี้อัตโนมัติ

## ทำได้จากข้อมูลโพสต์

- อ่านข้อความที่เก็บได้ ย้อนกลับไปตรวจต้นทาง และบันทึกโพสต์ไว้
- ค้นหาและกรองตามคำค้นที่เก็บมา คำค้นเป็นวิธีค้นพบโพสต์ ไม่ใช่การวินิจฉัยหรือหมวดที่ AI ยืนยัน
- ใช้เป็นจุดเริ่มต้นให้เจ้าของเติมเวลา ประวัติ สิ่งที่ลอง และคำถามหลัก เพื่อถาม MeongSilJang หรือทีมรักษาต่อ
- ใช้ทีมงานทบทวนโจทย์และออกแบบคำถามสัมภาษณ์/FAQ โดยตรวจโพสต์เต็มเพิ่มเติมก่อนสรุปข้อเท็จจริง

ยังสรุปความเห็นส่วนใหญ่ จุดที่สมาชิกเห็นต่าง ความถูกต้องของคำแนะนำในคอมเมนต์ ผลการรักษา หรือความถี่โรคของทั้งกลุ่มไม่ได้ ข้อมูลว่างไม่ได้แปลว่าโพสต์นั้นไม่มีคอมเมนต์

## UX ที่ลดขั้นตอน

หน้าแรกเหลือสองทางหลัก: เปิดชุด 200 โพสต์ หรือเขียนปัญหาของตัวเอง เครื่องมือเดิมและสถานการณ์ตัวอย่างเก็บไว้ในส่วนพับ

กด **เปิดชุด 200 โพสต์** → ตรวจตัวอย่างและจำนวน → **บันทึก 200 รายการ แล้วเลือกอ่าน** → **เตรียมคำถามไปถามต่อ** ข้อมูลยังอ่านในเครื่อง ไม่มีการเชื่อม TinyFish API และไม่เรียก AI อัตโนมัติ

เลือกชีต/เทียบคอลัมน์ให้อัตโนมัติตามหัวจริง แต่ยังเปิดแก้ได้ใน “เปลี่ยนชีตหรือคอลัมน์” หน้าอ่านเน้นข้อความ ข้อมูลที่ควรเตรียม และคำถามแก้ไขได้ ส่วนสรุป/ตรวจคอมเมนต์ไม่แสดงในโหมดนี้ คำถามเป็นแม่แบบเตรียมข้อมูล ไม่ใช่ผลวิเคราะห์เคสโดยโมเดล

ตัวกรองหลายหัวข้อเปลี่ยนเป็นช่องเลือก บนมือถือรายการโพสต์เลื่อนแนวตั้ง ปุ่มบันทึก ค้นหา และข้อมูลเดิมยังอยู่ การนำเข้าซ้ำรวมด้วยรหัส/ลิงก์ ไม่สร้างโพสต์ซ้ำ ส่วนข้อความตัดตอนยังมีป้ายกำกับและข้อจำกัดเมื่อกลับมาเปิดใหม่

ทดสอบผ่าน 51 tests รวมไฟล์จริง เปิดจากปุ่มหน้าแรก การเลือกชีต การอ่าน 179 ข้อความ/21 ลิงก์ว่าง และการนำเข้าซ้ำ ตรวจ HTTP หน้าเว็บ โมดูลใหม่ และไฟล์ Excel ได้ 200 ยังไม่ได้ตรวจภาพบนเบราว์เซอร์จริง/มือถือ
